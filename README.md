# AGF-Net-Attention-Gated-Fusion-Network-for-Automated-Feather-Scoring-in-Broiler-Breeders
The project introduces AGF-Net, a deep learning framework for automated six-class feather-score classification using RGB images. AGF-Net integrates multiscale feature extraction, CBAM attention, and adaptive gated fusion to capture both fine feather texture and broader feather-loss patterns.
